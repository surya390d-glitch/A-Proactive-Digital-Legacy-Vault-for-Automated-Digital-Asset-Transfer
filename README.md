🚀 Getting Started

1. Prerequisites
   
       Ensure you have Node.js installed (v18.0 or higher recommended).

2. Installation

       Clone the repository and install dependencies:
       git clone https://github.com/your-username/your-repo-name.git
       cd your-repo-name
       npm install

3. Environment Variables
   
       Create a .env.local file in the root directory and add your keys:
       NEXT_PUBLIC_API_URL=https://api.example.com
       DATABASE_URL=your_db_connection_string

4. Run Locally
   
       npm run dev
       Open https://asset-recovery-system.vercel.app to see the result.


📦 Deployment
This project is pre-configured for Vercel.

    1.Push your changes to GitHub.

    2.Connect your repository to the Vercel Dashboard.

    3.Vercel will automatically handle the build and provide a production URL.
